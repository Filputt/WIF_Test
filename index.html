SeedSigner WIF + PSBT Test-Data Generator TEST / DEMO

Generates fake, deterministic test data to exercise the SeedSigner “WIF key signing” workflow (scan WIF → scan PSBT → review → sign). Everything is computed locally in your browser. All keys are known demo keys and the transaction is invalid — never broadcast it.

5 How to test on SeedSigner

  1. On SeedSigner set the network to Mainnet (Settings → Network) to match this page (or switch this page to Testnet). The network must match or the scripts won't line up.
  2. SeedSigner → Settings → Advanced → enable “WIF keys” (and “BIP38 keys” too, if you are testing that path).
  3. On SeedSigner, scan the WIF QR (section 2) → the demo key is loaded.
  4. On SeedSigner, scan the PSBT QR (section 4) → review the (fake) transaction, then sign.
  5. Read the signed PSBT back from the device's animated QR and confirm the signature was added.
  6. Turn the WIF/BIP38 settings back off on the device when done.

IMPORTANT Do NOT broadcast this transaction — it spends an input that does not exist anywhere and is nonsense on-chain. It exists only to be signed and inspected.
